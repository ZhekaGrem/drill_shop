# DRILL v3 — аудит і план

Дата: 2026-09-21. База: `origin/v2`, `430f957`. Гілка: `v3`.

## Що є в проєкті

Робоча папка містить окремі репозиторії. `drill_shop` — магазин на Next.js 16 / React 19, App Router, TypeScript, Mantine, SCSS Modules, TanStack Query та Zustand. `drill-shop-backend` — Express / Prisma з PostgreSQL, Supabase Auth, Cloudinary, оплатою та доставкою. `drill-moto` — окремий Vite-проєкт гри; його готовий бандл синхронізується у `public/moto`. `gd-upstream` — вихідна база гри.

Основні шляхи: головна → колекція `/v2/a/[slug]` або каталог → кошик → checkout. Назви маршрутів v2 — частина чинних посилань; нова Git-гілка не потребує міграції URL. Колекції приходять із API, порядок і видимість головної визначають `home-collections` та `hidden-collections`. Архівність і порядок товарів залишаються даними бекенда.

Сильні сторони: локальні e-Ukraine / e-Ukraine Head, справжні фото та 3D-моделі, спільні токени, готові компоненти списків, каталогу, кошика, оплати й доставки. V3 використовує цю базу.

Проблеми v2: кілька великих героїв послідовно, календарна зміна візуальної ідентичності, слабка різниця між головним і допоміжним контентом, повторення підказок; відсутній кінцевий стан помилки колекцій. README описує старий шаблон магазину, тому архітектуру перевірено за кодом.

## Дизайн-напрям

Редакційна вітрина українського музичного мерчу. Теплий світлий фон `#f4f2ed`, чорнильний текст `#20211e`, стримані оливкові акценти. Темна версія: `#171915`, світлий текст `#f4f2ed`, акцент `#d9ed92`. e-Ukraine Head формує великий заголовок, e-Ukraine — читабельні описи й контролери. Невеликі радіуси, простір замість декоративних тіней, реальні речі в центрі композиції. Один провідний CTA на колекцію. Тема слухає системні налаштування, явний вибір має пріоритет.

## Етапи та критерії

1. Створити `v3` від актуальної v2; виключити наявні локальні зміни із коміту.
2. Додати scoped-токени editorial, стабільний default, SSR/pre-paint узгодження та підтримку попередніх виборів.
3. Головна: одна доступна неархівна колекція у 3D; решта — справжні обкладинки з посиланнями. Якщо всі архівні — показати першу із товарами. Приховані колекції відсіюються чинним правилом.
4. Додати loading / empty / error / retry, зберегти доступ до каталогу без API; FAQ через native details; skip-link для клавіатури.
5. Перевірити TypeScript, збірку, lint змінених файлів, регресії теми, маршрути та вигляд. Відомі проблеми бази записати окремо.
6. Закомітити лише файли v3 й запушити `origin/v3`.

## Межі змін

API, схему БД, ціни, оплату, доставку, авторизацію та бандл гри цей редизайн не змінює. Нові зображення і залежності не потрібні. Наявні збережені дизайн-переваги поважаються: щоб побачити v3 у старому браузері, обрати «Авто · DRILL v3» у локальній dev-панелі або відкрити сайт у новому профілі.

Локальне `DEV_MODE=true` і дублікати файлів `public/moto/* 2.*` не належать v3 та не повинні потрапити в коміт. Звіт перевірок — `validation.md`.
