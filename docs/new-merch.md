# Новий мерч / є. \*\*\*

У `/prokliatyi` дві старі колекції замінено новими героями **«Футболярочки»** (10 футболок) і **«Бобчанскі»** (11 худі). Товари створюються в backend з розмірами **S, M, L, XL, XXL, XXXL**. З попередніх колекцій перенесено описи «Прокляті футболки для святих людей» і «Прокляті боби для святих людей» та нульові залишки. Ціни за останнім уточненням власника — **1200 / 2100 грн**, включно з усіма розмірами. Старі записи знімаються з вітрини через `isActive=false` і `deletedAt`, зі збереженням історії.

## Як працює проєкт

До описів додано повідомлення власника: у футболках «Виготовлення футболянчанських — до 7 днів під обстрілами, але ми вас любимо», у худі «Виготовлення боб — до 7 днів під обстрілами, але ми вас любимо».

Магазин у `drill_shop` — Next.js, React Three Fiber і Feature-Sliced Design. Backend у сусідній папці `drill-shop-backend` відповідає за товари, колекції, кошик та замовлення. `useCollections` перетворює `/collections` у дані для `HomeHeroes`; `HeroVisual` завантажує модель у видимій області й перемикає Base Color через `useDesignMap`. Сцена клонує матеріали, тому різні герої не забирають модель або вибраний принт один в одного.

Розділ «є. \*\*\*» живе на `/prokliatyi`. Нові колекції приховані на головній та в загальному каталозі через `hidden-collections.ts`, а словомарка в хедері задається через `nav-worlds.ts`. `NewMerchHeroes` обирає дві нові колекції з API і передає їх у `HomeHeroes`: перемикачі, кнопки та сторінки товарів працюють з реальними slug. `new-merch.json` описує асети та є джерелом фазового засіву бази.

## UV і готові файли

Оновлення 2026-10-13: футболки мають **70%** попередньої ширини й висоти спереду та **80%** ззаду, навколо попередніх центрів. На худі 01–10 обидва боки повернуті до **100%** початкового розміру. Генератор працює з оригінальними принтами без накопичення масштабування. `layout-before-print-resize.json` у локальній папці генератора містить початкові координати. URL вебтекстур та постерів мають хеш версії.

Фінальні правки **лише футболок**: кістяну емблему №09 і вершника №06 піднято на 32 px у координатах 2048². Вершник збільшений на 15% від зменшеної версії, навколо центру. Спина №08 зменшена ще на 20%, рукав №04 — на 30%, зі збереженням центрів. Худі цими правками не змінюються.

Наступне уточнення: принт на спині футболки №07 «Щільний Дріл / Ніжна Оксана» збільшено ще на 20% навколо його центру. На футболці №09 із переду прибрано напис, залишено оригінальний окремий `emblem.png` та збільшено його до того самого розміру зони, що у вершника №06. Худі №09 зберігає свій напис. У «Бобчанскі» першим стоїть №11 «Проклятий вершник / на всі груди»; номери текстур залишаються ідентифікаторами дизайнів і не залежать від порядку в колекції.

## Відтворення

Потрібні встановлені залежності магазину (Sharp, meshoptimizer), Python з Pillow/PyMuPDF та Blender 5.2. У цій машині використано `/opt/homebrew/bin/python3.14`.

```sh
node scripts/new-merch/export-mesh.cjs
/opt/homebrew/bin/python3.14 scripts/new-merch/build-uv.py
/Applications/Blender.app/Contents/MacOS/Blender --disable-autoexec -b -P scripts/new-merch/render-posters.py -- "$PWD"
node scripts/new-merch/publish-posters.cjs
/opt/homebrew/bin/python3.14 scripts/new-merch/make-previews.py
node scripts/check-new-merch.cjs
```

Генератор перевіряє попадання фарби в UV-маски моделі. `check-new-merch.cjs` перевіряє 21 різну текстуру, SHA-256, розміри й формати, усі постери, звичайні зони кишені/капюшона та спільну проєкцію грудей/кишені №11; окремо контролює текстові колонки PDF 07. Герої перевірені в браузері на десктопі та ширині 390 px.

## Заміна колекцій у базі

`create-collections.cjs` використовує спільний фазовий рушій `seed-collections.cjs`. Спочатку створюються неактивні колекції й товари; `prepare-products.cjs` готує перед/спину 960×1200 і постер для Cloudinary. `images` завантажує їх. Після push і деплою асетів `activate --probe=https://ye-dril.com` перевіряє HTTP/MIME, моделі, актуальні URL текстур, назви, належність до колекцій, відсутність `deletedAt`, фото та всі шість розмірів. Нова серія активується і стара знімається **однією транзакцією**. `revalidate` очищає ISR нових і старих товарів. Записи потребують `--apply --confirm=new-merch`; залишки не збільшуються.

Наявну помилку Next.js 16.3 також усунуто: глобальна геометрія секцій Mantine Input перенесена з `Input.module.scss` до `globals.css` із тим самим селектором і значеннями. Інакше глобальний селектор без локального класу блокував збірку всієї сторінки.
