# v2 UI Audit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** прибрати три системні причини (неповний нічний блок токенів, розсинхрон Mantine, три
несумісні шкали висот), повернути навігацію, полагодити функціональні дефекти каталогу/кошика/
чекауту й вичистити тексти — так, щоб сайт був однаково справним у світлій і темній темі.

**Architecture:** правки йдуть від коренів до листя. Спершу `globals.css` +
`mantine-theme.ts` + `Providers.tsx` (E1) — це знімає більшість симптомів без окремих правок.
Далі навігація (E2), функціональні баги (E3), залишкові стики (E4), механічні sweep-и (E5-E6),
тексти (E7), видалення мертвого коду (E8).

**Tech Stack:** Next.js 16 (App Router), TypeScript, Mantine 8.3, SCSS-модулі, Zustand,
TanStack Query. Токени — CSS-змінні в `src/app/globals.css`.

**Spec:** `docs/superpowers/specs/2026-08-16-v2-ui-audit-design.md`

## Global Constraints

- Кольори, розміри, spacing — **тільки** токени з `globals.css`. Жодного hex у компонентах.
- Правило «Єдиного Джерела» стилізації (`CLAUDE.md`): Mantine props **АБО** SCSS-модуль **АБО**
  inline для динаміки. Не міксувати на одному елементі.
- FSD-межі: `shared` не імпортує з `features`; без cross-feature імпортів.
- Кожен новий токен супроводжується коментарем із порахованим контрастом — як уже зроблено для
  світлої теми (`globals.css:275`).
- Пороги: **4.5:1** звичайний текст, **3:1** великий (≥24px або ≥18.5px bold) і нетекстові
  контроли/межі (WCAG 1.4.3, 1.4.11).
- Мова UI — українська, типографські лапки «», апостроф `ʼ`, три крапки `…`.
- Тестів у проєкті немає. Верифікація кожної задачі: `npx tsc --noEmit` → `npm run lint` →
  візуальна перевірка **в обох темах** через `/v2/dev`. Перед завершенням етапу — `npm run build`.
- Рішення власника від 2026-08-16: **нижню панель повертаємо**, **темну тему лишаємо й доводимо
  до ладу**.
