# План імплементації · Концепція 2 «Мерч та Стрітвір»

> Оглядовий план; повний покроковий — після вибору концепції.
> Спека: `../specs/2026-08-16-concept-2-streetwear-design.md`.
> Може впроваджуватись ПОВЕРХ К1 як «режим дропу» (поля і бюджет сумісні).

## Етап 0 — спільний (див. 2026-08-16-concepts-common-plan.md)

## Етап 1 · БД: нові поля — S (бекенд + CI-міграція)
- [ ] Міграція A: `collections.tile_color VARCHAR(100)`.
- [ ] Міграція B: `label_style VARCHAR(20) DEFAULT 'capsule'` на
      `collections` і `products`.
- [ ] Селекти колекцій/товарів + інтерфейси + ФОРМЕР-ВАЙТЛІСТ товарів
      (відома пастка — поле без формера не долетить до фронту).
- [ ] Диф-валідація проти прод-БД; пуш → CI накатує.
- Верифікація: GET /collections віддає обидва поля.

## Етап 2 · Токени acid/red — S
- [ ] `globals.css`: `--acid #CCFF00`; правило двох червоних (великі
      `#FF0000`, дрібний текст `#a63c48`).
- [ ] Хелпер `capsuleStyle`: на acid-фонах текст темний (розширити чинну
      умову «gradient → темний» списком світлих фонів або перевіркою яскравості).
- Верифікація: капсула `#CCFF00` з чорним текстом в обох темах.

## Етап 3 · Плитки + сторіз — L (ядро концепції)
- [ ] Відродити механіку HeroTiles з історії git (коміти v2 до чистки
      d63001d-епохи) як data-driven: плитки = колекції з БД,
      колір = `tile_color` ?? перший свотч.
- [ ] Сторіз-бари: 5с автогортання, тап = вибір + пауза 15с, свайп по
      сцені = пауза; `prefers-reduced-motion` → автогортання off.
- [ ] Під плитками — один живий герой активної колекції (сцена одна;
      текстурні колекції свопляться без remount).
- Верифікація: автогортання по трьох колекціях, пауза на взаємодію,
  reduced-motion вимикає авто.

## Етап 4 · Стікер на візуалі — M
- [ ] Рендер `label_style='sticker'`: плашка над сценою (верхній правий кут,
      rotate(-3deg), тінь, `pointer-events:none`) у героях і на /v2/a.
- [ ] Аудит-сторінка: показувати style поряд із капсулою.
- Верифікація: перемикання style у Studio міняє вигляд без деплою.

## Етап 5 · Темна базова / публічний тумблер — S
- [ ] Інлайн-скрипт: default `'dark'` (варіант A) І/АБО `ThemeToggle` без
      умови DEV_MODE + мікроанімація іконки (варіант B; рішення команди).
- Верифікація: перший візит = темна; тумблер (якщо B) працює в проді.

## Порядок і залежності
1 (бекенд, чекає CI) → 2 → 4; 3 незалежно після 1; 5 — будь-коли.

## Definition of done
Поля в API; плитки-сторіз керують героєм; стікер живе з БД; правила acid/red
у гайді; режим теми за рішенням команди.
