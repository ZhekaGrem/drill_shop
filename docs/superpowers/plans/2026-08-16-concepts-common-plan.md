# Етап 0 · Спільні роботи трьох концепцій

> Це можна (і варто) зробити ДО вибору концепції — знадобиться будь-якій.

- [ ] **Хелпер контрасту позначок** — узагальнити `capsuleStyle`: колір тексту
      з яскравості фону (зараз лише «gradient → темний»); покриє acid (К2),
      iOS-blue (К1) і градієнт (К3) одним правилом. — S
- [ ] **Верифікаційний прохід тем**: чек-лист сторінок (головна, /v2/a,
      каталог, товар, кошик, чекаут, аудит) світла/темна — база порівняння
      «до» для будь-якої концепції. — S
- [ ] **Жестовий прототип** (потрібен К1, корисний усім): картка героя в
      горизонтальному скролі + драг-обертання сцени на реальному телефоні —
      найризиковіша невідомість усіх механік. — M
- [ ] **Гайд позначок у дизайн-доці**: таблиця «капсула vs крапка vs стікер»
      зі словником текстів — концепції лише перемикають дозволені стилі. — S
- [ ] Рішення команди: якщо База = К1 + «режим дропу» = К2, міграції К2
      (tile_color, label_style) можна котити разом з етапом 1 К1 — CI один раз.

## Мапа вибору

| Обрали                                | Виконуємо                                                                     |
| ------------------------------------- | ----------------------------------------------------------------------------- |
| К1                                    | Етап 0 → план К1; опційно міграції К2 «про запас»                             |
| К2                                    | Етап 0 → план К2                                                              |
| К3                                    | Етап 0 → план К3 (найкоротший шлях)                                           |
| К1 + резерв К2 (рекомендація команди) | Етап 0 → план К1 повністю → з К2 лише етапи 1, 3, 4 як фіче-флаг «дроп-режим» |
