**Goal:** Build model-compatible UV textures for the ten designs in `../новий мерч` and add two new heroes to `/prokliatyi`.

**Tech stack:** Existing Next.js / React Three Fiber, Meshopt decoder, Sharp, Pillow, PyMuPDF, Blender.

## Constraints and decisions

- Reuse `tshirt.glb` and `hoodie-3.glb`; no duplicate runtime geometry.
- Preserve original files and existing heroes, backend data, and the user's DEV_MODE edit.
- Shirt front: left torso island; back: middle torso island. Confirm with actual mesh and renders.
- Hoodie front: chest above pocket, y 662–837 in 2048 coordinates. Back: below hood, y 106–502, width at most 250.
- Black cloth; single-color black artwork is converted to light ink, full-color artwork retained. PDF 7 uses the front from the first PDF and back from the second.
- Build full-resolution PNG atlases, labeled guides, extracted print assets, hashed placement manifest, and 4096 WebP q94 runtime textures. Lossless PNGs remain available for export.
- Every variant gets a real rendered poster. New heroes work even if the collections API is unavailable.
- No deployment or production DB mutation is needed to add and inspect local heroes.
