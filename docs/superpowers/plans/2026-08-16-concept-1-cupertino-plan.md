> Спека: `../specs/2026-08-16-concept-1-cupertino-design.md`.
> Оцінки: S ≈ до півдня, M ≈ день, L ≈ 2+ дні.

## Етап 0 — спільний (див. 2026-08-16-concepts-common-plan.md)

## Етап 1 · Темна палітра OLED — M

- [ ] `globals.css`: дельта dark-блоку (`--background #000`, `--surface-card
  #1C1C1E`, `--surface-muted #2C2C2E`, `--border-subtle #38383A`;
      `--gradient-page` dark → суцільний `#000`).
- [ ] Межа навбару/футеру на OLED: перевірити `--border-inverse-subtle`
      (щоб чорне не зливалось із чорним) — правка, якщо треба.
- [ ] Пройти темну тему по сторінках: головна, /v2/a, каталог, кошик-дровер,
      аудит. Фіксити плями точково.
- Верифікація: скріншоти світла/темна обох ключових сторінок; жодного
  сірого «острова» старої палітри.

## Етап 2 · Акцент iOS — S

- [ ] `--accent`: `#007AFF` / `#0A84FF` (пара light/dark).
- [ ] Аудит вживань дрібним текстом: усі лінки <18px — або жирні, або
      лишаються `#0073e6` (правило зі спеки, 4.02:1).
- Верифікація: grep вживань `--accent` + візуальний прохід.

## Етап 3 · Peek-карусель героя — L (ядро концепції)

- [ ] `Home.tsx`: стек героїв → горизонтальний скрол-контейнер зі
      `scroll-snap` по центру; картка = чинний герой-вміст.
- [ ] Правило «жива сцена лише в центрі»: IntersectionObserver ≥60% →
      mount сцени; бічні — рендер-постер `<Image>`.
- [ ] Жести: перевірити конфлікт свайпу каруселі з драг-обертанням сцени
      (`touch-action` на стейджі vs контейнері) — НА РЕАЛЬНОМУ ТЕЛЕФОНІ
      (закон проєкту: тач-жести в емуляторі брешуть).
- [ ] Стан вибраних дизайнів на колекцію — чинний словник; активна колекція
      = снап-позиція.
- Верифікація: 3 колекції гортаються зі снапом; WebGL-контекст один;
  свайп по сцені крутить футболку, по краях — гортає.

## Етап 4 · Системна тема — S

- [ ] Інлайн-скрипт у `layout.tsx`: години → `matchMedia('(prefers-color-scheme:
  dark)')`; localStorage-вибір перекриває.
- [ ] `ThemeToggle`: інтервал-годинник → `change`-слухач medía-query.
- Верифікація: перемикання теми ОС міняє сайт наживо без явного вибору;
  явний вибір липкий.

## Етап 5 · Позначки за гайдом — S (дані, без коду)

- [ ] `label_color` активних капсул → `var(--accent)`; крапки — статуси.
- [ ] Гайд у дизайн-доці: пігулка=«Новинка», крапка=статуси, стікери заборонені.

## Порядок і залежності

1 → 2 → 4 можна паралельно з 3; 5 — будь-коли після 2.
Найризиковіший — етап 3 (жести) — почати з нього прототипом.

## Definition of done

Обидві теми чисті на всіх ключових сторінках; карусель зі снапом і одною
сценою; системна тема; гайд позначок застосований у БД.
