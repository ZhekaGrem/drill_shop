# Редизайн v2: дизайн-мова diia.gov.ua

**Дата:** 2026-08-08
**Гілка:** `v2`
**Статус:** затверджено користувачем (секції 1–4 схвалені по черзі)

## Мета

Повністю замінити візуальну мову магазину shchilnui Drill (pixel-art: бежевий/зелений/жовтий, radius 0, offset-тіні) на дизайн-мову сайту diia.gov.ua. Функціонал, FSD-структура та бізнес-логіка не змінюються. Паралельно вбудовуються 15 UX-виправлень з дизайн-розбору (список нижче).

## Скоуп

**Входить:** усі покупецькі сторінки (головна, каталог, товар, кошик, чекаут, success/failed, профіль, auth), Header/Footer, статичні сторінки (FAQ, доставка, оферта, privacy, about, contact).
**Не входить:** `/admin`, `/telegram` (підтягнуться частково через спільні токени/компоненти, цілеспрямовано не чіпаємо).

## Підхід: Token-first каскад (варіант A)

Проєкт вже токенізований через CSS-змінні в `globals.css` — редизайн виконується заміною значень токенів + проходами по екранах для чистки локальних хардкодів. Без паралельного UI-kit, без переписування з нуля.

## Референс: факти з живого CSS diia.gov.ua

Зняті з `https://diia.gov.ua/combine/…` (бандл, серпень 2026):

- Шрифти: `e-ukraine` (300 Light / 400 Regular / 500 Medium), `e-ukraine-heading` (e-UkraineHead) для заголовків; woff, `font-display: swap`
- Body: фон `#fff`, основний текст чорний, другорядний `#606060` (часто weight 300)
- Фірмовий фон секцій: `#E7EEF3`
- Primary-кнопки: чорний pill — radius 40px, padding 16px 25px, білий текст, 16px/24px, `letter-spacing: -0.02em`, transition 0.2s ease-in-out
- Пошук/інпути: білий pill radius 100px, текст `#606060` weight 300
- Роздільники-акценти: `2px solid #000`
- Фокус: `outline: 3px solid #0073e6; outline-offset: 2px`; глибокий синій `#004BC1` для текстових акцентів
- Картки: radius 10–32px

**Типографіка:**

- Кнопки/заголовки: `letter-spacing: -0.02em`
- Капс і condensed зникають (виняток — лого за потреби); Rubik та IBM Plex видаляються з підключення

## Секція 2: Спільні компоненти

**Button** (`shared/components/Button`):

- `primary`: чорний pill (40px radius, 16×25 padding, білий текст), hover `#333`, transition 0.2s ease-in-out; без transform-«вдавлювань»
- `secondary`: білий pill, чорний текст, тонкий чорний бордер
- `ghost`: текстова, hover синій `#0073e6`
- Варіанти `yellow`/`red` видаляються з API; небезпечні дії — ghost з червоним текстом; усі використання оновлюються в екранних проходах

**Інпути** (повний перепис компонентних стилів `mantine-theme.ts`): білі поля, radius 8–12px (пошук — pill 100px), лейбл зверху, плейсхолдер weight 300 `#606060`, фокус — синій outline. Бежевий фон/зелений underline зникають. Checkbox 4px radius / Radio коло, чорна заливка, біла галочка (заміна `chekbox.svg`).

**Badge**: pill; `promo`/`discount` червоний (єдиний червоний у системі), `featured` чорний, `outOfStock` сірий `#606060`; висота ≥24px.

**Картки** (ProductCard, CheckoutCard, Paper): білі, radius 16px, без бордера, тінь на hover (легкий підйом). Glitch-ефект видаляється; hover-swap фото лишається.

**Notification/Alert/Modal/Drawer**: radius 16px, білий фон, м'яка тінь, 2px чорна лінія зверху як фірмовий акцент.

**Правило станів (anti-slop):** кожен компонент перевдягається з повним набором hover / focus-visible / active / disabled / loading. Рівень доведеності однаковий скрізь — жодного «одна картка гарна, сусідні старі».

## Секція 3: Екрани (з вбудованими UX-фіксами)

Нумерація фіксів — з дизайн-розбору від 2026-08-08 (розмова, розбір чотирьох зон).

**Header:** білий, sticky, тонка нижня межа. Лого зліва; десктоп ≥1024px — видима навігація: Каталог, Розпродаж, Про нас, Контакти (№3); справа пошук-pill, кошик, профіль. Лічильник кошика — тільки бейдж (№11). Іконки 24px, тап-зона 44px. Hover сірий. Мобільний drawer: єдиний регістр пунктів (№13). Пошук: дропдаун з популярними категоріями + останніми запитами при фокусі (№7).

**Головна:** хедер присутній (№2), fixed-оверлей і `z-index:9999` видаляються. Секції: hero на `#E7EEF3` — зліва e-UkraineHead-заголовок + чорна pill-CTA «До каталогу», праворуч Spline 3D-футболка (лишається, з наявним webp-плейсхолдером); картки категорій у стилі сервіс-карток diia.gov.ua; PopularProductsSlider; смуга переваг (доставка/оплата/обмін).

**Каталог:** фільтри в білій картці, чипи-фільтри pill. Картка товару: назва без підміни на опис при hover (№5); ціна weight 500; варіанти — radio-чипи (семантика radio, №6) висотою ≥32px (№1). «В кошик» — secondary pill. «Всі товари завантажено» — сірий (№4a); порожній результат — empty-стан з іконкою, поясненням і кнопкою «Скинути фільтри» (№4b).

**Сторінка товару:** галерея на білій картці; назва e-UkraineHead; ціни: стара закреслена сіра, акційна червона; розміри — pill-чипи; ряд «кількість + size-guide» — одна висота, SVG-іконка замість `btnInfo.jpg` (№10); «Купити зараз» чорна pill, «В кошик» біла pill.

**Кошик/чекаут:** товари в картках-рядках; видалення з undo-тостом ~5с (№8). Чекаут: секції-картки на `#E7EEF3`, підсумок-«документ» з 2px чорною лінією зверху, sticky. Юридична примітка без alert-іконки (№14). Success: без UUID, тільки номер замовлення (№12).

**Footer:** `#E7EEF3`, 2px чорна лінія зверху; «Зв'язок з нами» → `/contact` (№9); додати лінк на Політику конфіденційності. Видалити закоментований код Favorites/«Очистити кошик» (№15).

**Статичні сторінки:** успадковують токени; прохід лише для чистки хардкодів.

## Секція 4: Порядок робіт і перевірка

Кожен етап — окремий коміт у `v2`; сайт робочий після кожного:

1. Шрифти: перевірка ліцензії e-Ukraine → woff у `public/fonts` → `next/font/local` → layout
2. Токени: `globals.css` :root + body/headings; злиття `design-tokens.ts`
3. Спільні компоненти: Button, Badge, mantine-theme (інпути/checkbox/modal/notification)
4. Header + Footer (навігація, пошук-підказки, фікс лінків)
5. Каталог + ProductCard (radio-чипи, empty-стани)
6. Сторінка товару
7. Кошик + чекаут + success/failed
8. Головна (hero зі Spline, категорії, слайдер)
9. Статика + фінальна чистка: `grep -rE '#33603b|#e0ddca|#e6db1b|glitch'` по `src/` → нуль збігів

**Перевірка кожного етапу:** `npm run build` + `npm run lint` — green обов'язково; Playwright-скріншоти ключових сторінок на 375px і 1440px. Фінал: ручний прохід флоу головна → каталог → товар → кошик → чекаут.

**Ризики:**

- Ліцензія e-Ukraine → фолбек Inter (рішення на кроці 1)
- Локальні SCSS-хардкоди поза каскадом токенів → закриває греп-чистка кроку 9
- Найтовщі етапи 4–8 незалежні між собою — можна переставляти за потреби
