# Перемикач дизайнів 3D-футболки в герої

**Дата:** 2026-08-12
**Гілка:** `v2`
**Статус:** спека затверджена, план не написаний

---

## Задача

Дизайнер додав другий дизайн «NIЖNA OKCANA» — фіолетовий
(`tshirt 3d/NO violet texture.png`, 7936², запечений під UV чинного крою T28:
передня й задня панелі на своїх місцях). Підняти його на UI **другим дизайном
поруч із червоним**: перемикач у герої, спільна геометрія, миттєвий своп
текстури. Це перший реальний запуск архітектури «одна модель + N текстур»,
спроєктованої під майбутні 50 футболок.

Свідоме рішення (зафіксоване з користувачем): Tripo-модель `~/Desktop/3d.glb`
НЕ використовується — це стара AI-генерація суттєво гіршої якості за T28.

## Асети

| Асет                | Звідки                                   | Куди                                     |
| ------------------- | ---------------------------------------- | ---------------------------------------- |
| Фіолетова текстура  | `tshirt 3d/NO violet texture.png` (7936²) | `public/textures/tshirt-no-violet.jpg` (2048², JPEG q88, очік. ~60–120 КБ) |
| Фіолетовий фолбек   | Blender-рендер GLB із підміненою мапою    | `public/assets/img/tshirt-fallback-violet.webp` (1200², прозорий фон)      |

- GLB (`public/model/tshirt.glb`) **не змінюється** — червоний дизайн лишається
  запеченим дефолтом і працює як зараз.
- Фіолетова текстура вантажиться лише на вимогу; після готовності сцени —
  тихий префетч, щоб перше перемикання було миттєвим.

## Рантайм-своп (`useDesignMap.ts`, новий хук)

- Вхід: `scene: Group`, `mapUrl?: string`. Без `mapUrl` (або для дефолту) —
  нічого не робить: у матеріалі лишається запечена червона мапа.
- Завантаження через `THREE.TextureLoader` у `useEffect` — **без Suspense**:
  до готовності нової текстури висить стара, сцена не блимає.
- При готовності: новій текстурі виставити `flipY = false`,
  `colorSpace = SRGBColorSpace`, `anisotropy = min(16, ліміт GPU)` — і одним
  присвоєнням `material.map = texture`. Рекомпіляція шейдера не потрібна
  (define USE_MAP уже активний), тож **вітер, lag і стрибок не зачіпаються**.
- Повернення на дефолт: зберегти посилання на оригінальну запечену текстуру
  при першому свопі й повертати саме її (не перевантажувати з GLB).
- Кеш завантажених текстур — у ref хука (Map url → Texture): повторні
  перемикання миттєві, без повторних запитів.
- `TshirtScene` отримує прозорий проп `mapUrl?: string` і викликає хук.
  Сцена не знає назв дизайнів — список дизайнів належить HeroVisual.
  Цей самий проп — майбутній API для в'юера на сторінці товару.

## UI перемикача (у HeroVisual, DOM)

- Два круглі свотчі (червоний / фіолетовий) під візуалом футболки,
  горизонтально по центру. Кольори свотчів — приблизні кольори принтів.
- Стиль — тихі контроли Дії: токени з `globals.css`, `--radius-pill`,
  прес-фідбек моушн-системи (`--motion-press-scale`), активний свотч має
  видиму обводку (`--border-...`), тап-зона ≥ 44×44px, `aria-label`
  («Дизайн: червоний / фіолетовий»), `aria-pressed` на активному.
- Стан — локальний `useState<'red' | 'violet'>` у HeroVisual, дефолт `red`.
- **Reduced motion**: сцени немає, але перемикач працює — свопає статичний
  фолбек (`tshirt-fallback.webp` ↔ `tshirt-fallback-violet.webp`).
  Той самий своп фолбека і до завантаження сцени.

## Крайові випадки

| Випадок                             | Поведінка                                                     |
| ----------------------------------- | ------------------------------------------------------------- |
| Клік по фіолету до завантаження     | висить червона мапа; своп відбудеться при готовності текстури |
| Швидке перемикання туди-сюди        | застосовується лише останній вибір (guard за поточним url)    |
| Помилка завантаження текстури       | лишається чинна мапа; console.warn; свотч не «залипає»        |
| Ремаунт сцени (кеш useGLTF)         | оригінальна мапа відновлюється з посилання, кеш текстур новий |
| Reduced motion / сцена ще вантажиться | перемикач свопає статичні фолбеки                           |

## Тестування

Тестової інфри немає. Ручна перевірка:

- перемикання червоний ↔ фіолетовий: миттєво (після префетчу), без блимання
  і без перезапуску сцени; оберт/вітер/нахили не перериваються;
- фіолетова спина: тур-принт читається, чорних плям немає (чорне тло текстури
  + чинна анізотропія);
- reduced motion: перемикач свопає фолбек-фото;
- `npx tsc --noEmit`, ESLint по змінених файлах, `npm run build` зелені.

## Свідомо не робимо (YAGNI)

Більше двох дизайнів в UI (архітектура тримає N, інтерфейс поки на 2),
збереження вибору між візитами, синхронізація з каталогом/товарами,
cross-fade анімація переходу мапи, прев'ю-тултіпи на свотчах.
