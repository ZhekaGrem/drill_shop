# «Підвішена маса» — інертний idle-рух 3D-футболки

**Дата:** 2026-08-11
**Гілка:** `v2`
**Статус:** спека затверджена, план не написаний

---

## Задача

Зараз футболка обертається ідеально рівно (0.3 рад/с) — читається як турнтейбл:
статична, безмасова, «прибита» до місця. Мета — відчуття підвішеної речі з
масою: нерівномірний оберт, повільні маятникові коливання, дрейф і головне —
**вторинний рух тканини**: поділ і рукави відстають від «тіла» при змінах
швидкості оберту й наздоганяють.

Обраний варіант (із трьох запропонованих): **A — «Підвішена маса»** — повний
оберт зберігається, маса передається хореографією і шейдерним відставанням.
Числа нижче — цільові орієнтири, тюняться на око.

## Рух

| Компонент          | Орієнтир                                                                  |
| ------------------ | ------------------------------------------------------------------------- |
| Базовий оберт      | 0.2 рад/с (замість 0.3)                                                   |
| Дихання швидкості  | ω(t) = 0.2·(1 + 0.35·sin(0.23·t) + 0.2·sin(0.37·t + 1.7)) → ~0.09–0.31    |
| Нахил X            | ±2.5°, період ~9.3 с                                                      |
| Нахил Z            | ±2.0°, період ~7.1 с (періоди некратні — патерн не зациклюється помітно)  |
| Вертикальний дрейф | ±0.8 % висоти моделі, період ~11 с                                        |
| Lag тканини        | тангенційно, ∝ згладжене кутове прискорення; пік на подолі ≈ 5–8° еквів.  |

- Кут оберту — **інтеграл** ω(t) по кадрах (rotation.y += ω·dt), не функція
  від t: так дихання швидкості дає справжні прискорення для lag.
- Кутове прискорення α = Δω/Δt, згладжене експоненційно (~5 1/с), щоб тканина
  тягнулась плавно, без тремтіння.
- delta клампиться (~1/30 с) — після фонової вкладки без телепортів і сплесків α.

## Інерція тканини (шейдер)

До chunk-а вітру в `useWind` додається тангенційний доданок:

```
transformed += vec3(-position.z, 0.0, position.x) * uWindLag * windW;
```

- `vec3(-z, 0, x)` — тангенс оберту навколо Y, ненормований: радіус входить у
  величину природно (далі від осі — більше відставання, фізично коректно).
- Вага — та сама `windW` (плечі нерухомі, поділ і рукави тягнуться).
- `uWindLag` = −α_згладжене × gain — новий uniform; живе в `material.userData`
  поряд з `uWindTime` (та сама ремаунт-безпека при кеші useGLTF).
- **Урок багу з проколами шарів врахований**: тангенційний напрям у точці
  однаковий для зовнішнього і внутрішнього шару тканини — шари рухаються
  разом, взаємопрокол неможливий (як і радіальний вітер).

## Архітектура

Все в `src/widgets/HeroVisual/`:

- **`useIdleMotion.ts`** (новий) — хук зі станом у refs (інтеграл кута,
  попередня ω, згладжений lag). `step(group, delta, elapsed)`: мутує
  `rotation.y` (інтеграл ω), `rotation.x/z` (нахили), `position.y` (дрейф)
  зовнішньої групи; повертає lag для шейдера. Жодного setState на кадр.
- **`useWind.ts`** — другий uniform `uWindLag`, тангенційний доданок у chunk,
  сигнатура кроку стає `(elapsedTime, lag)`.
- **`TshirtScene.tsx`** — ручний рядок `rotation.y += delta·SPEED` замінюється
  викликом idle-кроку; lag передається у windStep. Guard `hasBakedRotation`
  зберігається: якщо в моделі колись з'явиться запечена анімація, idle-рух не
  застосовується взагалі.

Нових залежностей немає; GLB не змінюється; стрибок (`interactive`), фолбек і
reduced-motion гейт — без змін (при reduced motion сцена, як і раніше, не
вантажиться взагалі).

## Композиція і межі

- Нахили й дрейф — на **зовнішній** групі; стрибок мутує внутрішню — не
  конфліктують ні трансформами, ні pivot-ом.
- Bounds margin 1.15 має вмістити нахил ±2.5° + дрейф 0.8 % (+ апекс стрибка
  в interactive-режимі) — перевірити візуально; за потреби margin → 1.2,
  камеру не рухати.
- Тангенс рахується з нормалізованих квантованих координат моделі — напрям
  коректний (масштаб вузла рівномірний), величини калібруються констанами
  в тих самих юнітах, що вітер.

## Крайові випадки

| Випадок                         | Поведінка                                                  |
| ------------------------------- | ---------------------------------------------------------- |
| Фонова вкладка → повернення     | кламп delta + згладження α — без ривка тканини             |
| Стрибок (interactive) під idle  | незалежні групи; lag живе своїм життям — складається       |
| Модель із запеченою анімацією   | idle-рух вимкнений guard-ом hasBakedRotation               |
| Ремаунт сцени (кеш useGLTF)     | uWindLag у userData — патч не дублюється, uniform спільний |

## Тестування

Тестової інфри немає. Ручна перевірка:

- швидкість оберту помітно «дихає»; є квазі-паузи, але оберт не зупиняється;
- при прискореннях поділ/рукави відстають і наздоганяють; плечі стабільні;
- нахили й дрейф повільні та ненав'язливі; принт читається весь оберт;
- чорних плям немає (шари не колються) — окремо глянути спину кілька обертів;
- `npx tsc --noEmit`, ESLint по змінених файлах, `npm run build` зелені.

## Свідомо не робимо (YAGNI)

Повний фізичний маятник (опція B), drag-to-spin з інерцією (опція C — кандидат
для сторінки товару), шум/рандомізація руху, зупинки оберту, зовнішні
налаштування.
