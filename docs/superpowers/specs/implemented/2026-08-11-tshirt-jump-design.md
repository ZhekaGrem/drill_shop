# Інтерактивний стрибок 3D-футболки в герої

**Дата:** 2026-08-11
**Гілка:** `v2`
**Статус:** спека затверджена, план не написаний

---

## Задача

3D-футболка в герої обертається, але ніяк не реагує на користувача. Додаємо
пасхалку: натиск на футболку — вона «присідає», відпускання — пружний стрибок
із squash & stretch і м'яким приземленням. Обертання не переривається.

Рух говорить мовою Дії: миттєвий старт, гальмування в кінці, коротко. Стрибок —
це 3D-продовження патерну press-фідбеку (`--motion-press-scale`): натиск =
присідання, відпускання = енергія назовні.

Числові значення нижче — цільові орієнтири; точні цифри тюняться на око під час
імплементації, не виходячи за загальні межі (весь стрибок ≤ ~700 мс).

## Поведінка

Стан-машина:

```
idle → pressed → rising → falling → landing → idle
```

| Фаза    | Що відбувається                                                  | Орієнтири                               |
| ------- | ---------------------------------------------------------------- | --------------------------------------- |
| pressed | сплюскування: scale.y ≈ 0.88, scale.x/z ≈ 1.06, ease-out         | ~90 мс; тримається, поки палець утримує |
| rising  | вертикальний імпульс; розтяг (scale.y > 1) пропорційно швидкості | апекс ≈ 12–15 % висоти моделі           |
| falling | параболічне падіння під «гравітацією»                            | —                                       |
| landing | squash від швидкості удару, потім згасаюча пружина до scale 1    | 2–3 коливання, ~250 мс                  |

- Повна тривалість від відпускання до спокою ≤ ~700 мс.
- Повторний натиск під час rising/falling/landing ігнорується (guard).
- `pointerleave` у фазі pressed → м'яке повернення scale до 1 **без** стрибка.
- Швидкий тап (up майже одразу після down): відпускання чекає завершення
  присідання — анти-фаза відіграється завжди, стрибок не «зривається» з місця.
- Присідання і приземлення візуально притиснуті до низу: масштабування
  відносно нижньої межі моделі (pivot внизу габаритів), а не центру — інакше
  футболка «стискається в повітрі», відриваючись від тіні.
- Обертання (наявний useFrame, 0.3 рад/с) працює безперервно в усіх фазах.

## Архітектура

Все в межах `src/widgets/HeroVisual/`:

- **`useJump.ts`** (новий) — хук зі стан-машиною і математикою пружини.
  Повертає обробники `onPointerDown/Up/Leave` і функцію кроку анімації.
  Весь стан у refs; жодного setState на кадр — нуль React-рендерів під час
  анімації. Крок викликається з наявного useFrame сцени; delta клампиться
  (~1/30 с), щоб після фонової вкладки не було телепорту.
- **`TshirtScene.tsx`** — підключає хук: вішає обробники на групу футболки
  (R3F-рейкаст по мешу), викликає крок у useFrame, додає `useCursor` із drei
  (курсор pointer над футболкою). Компонент лишається < 150 рядків.

Нових залежностей немає (`useCursor` — із `@react-three/drei`, вже в deps).
GLB не змінюється.

## Інтеграція з наявною сценою

- Стрибок мутує `position.y` і `scale` групи всередині `<Bounds>`; кадрування
  камери від transform-ів не перераховується, тож підгонка не збивається.
- Запас `margin: 1.15` має вмістити апекс — перевірити візуально; якщо
  кліпиться, підняти margin до ~1.2, а не рухати камеру чи модель.
- Тінь-«стенд» (`styles.shadow` у HeroVisual) — DOM-елемент; на стрибок
  свідомо не реагує: синхронізувати DOM із canvas покадрово = зайва
  зв'язність заради нюансу.

## Reduced motion і доступність

- `prefers-reduced-motion` вже гейтить завантаження сцени в HeroVisual
  (лишається статичне фото з alt) — стрибка автоматично немає, нового коду
  не треба.
- Сцена — декоративна пасхалка: без клавіатурного фокуса, без `role="button"`,
  без aria-анонсів.

## Крайові випадки

| Випадок                          | Поведінка                                                   |
| -------------------------------- | ----------------------------------------------------------- |
| Повторний клік у польоті         | ігнорується                                                 |
| `pointerleave` під час pressed   | м'яке повернення, без стрибка                               |
| Вкладка згорнута посеред польоту | delta клампиться; анімація коректно дограється              |
| Resize під час польоту           | Bounds перекадровує від габаритів моделі; стрибок відносний |
| Швидкий тап на мобільному        | присідання відіграється повністю, потім стрибок             |

## Тестування

Тестової інфри в репо немає. Ручна перевірка:

- клік мишею і тап у мобільній емуляції — повний цикл стрибка;
- утримання → присідання тримається; відведення курсора → повернення без стрибка;
- увімкнений prefers-reduced-motion → сцени немає, фото на місці;
- обертання не зупиняється в жодній фазі;
- апекс не кліпиться краями полотна;
- `npm run lint` і `npm run build` зелені.

## Свідомо не робимо (YAGNI)

Звук, частинки, сальто/оберти в польоті, cloth-брижі (вершинний шейдер),
idle-стрибки без взаємодії, реакція DOM-тіні, налаштування анімації ззовні.
