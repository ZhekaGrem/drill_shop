# Концепція 2 · «Мерч та Стрітвір» — специфікація

> Статус: кандидат; рекомендація команди — тримати в резерві для великих дропів
> і розпродажів (режим ажіотажу). Теза: швидке споживання як у соцмережах,
> зухвалість «гонорового вар'ятства».

## 1. Токени (дельта)

| Токен                   | Було         | Стане                                                          | Контраст-вердикт                                                                                                                                                    |
| ----------------------- | ------------ | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Новий `--acid`          | —            | `#CCFF00` (обидві теми)                                        | ⚠️ на білому **1.18:1** — ЗАБОРОНЕНИЙ як текст/іконка на світлому. Дозволено: **фон позначки з чорним текстом** (17.9:1 ✓) і акценти на чорних поверхнях (17.9:1 ✓) |

| Тема за замовчуванням   | світла вдень | **темна базова**                                               | нічна палітра чинна (`#1b211f`-сім'я) — без змін                                                                                                                    |

## 2. Герой: Плитки + сторіз (ідея власника, кандидат 6)

- Верхній блок: ряд **кольорових квадратів колекцій** (56–64px, радіус 12),
  під кожним — прогрес-смужка сторіз.
- Автогортання: активна колекція міняється кожні **5 с**; смужка активної
  анімується шириною, пройдені — заповнені, майбутні — порожні. Тап по
  квадрату/смужці = ручний вибір і **пауза автогортання на 15 с** (drop-off
  захист); свайп по сцені теж ставить паузу.
- Нижче — ОДИН живий герой активної колекції (сцена одна — WebGL 1;
  перемикання колекції = зміна designs у тій самій сцені, без remount канваса
  там, де модель спільна).
- **Дані кольору плитки:** нове поле `collections.tile_color VARCHAR(100)`
  (hex або градієнт). Fallback, поки поле порожнє: перший свотч колекції.
  Міграція: `ALTER TABLE "collections" ADD COLUMN "tile_color" VARCHAR(100);`
- `prefers-reduced-motion` → автогортання вимкнене, лишається ручний тап.

## 3. Теми

- Варіант A (базовий): темна за замовчуванням завжди; світла — лише явним
  вибором. Інлайн-скрипт: default `'dark'`.
- Варіант B: тумблер 🌙/☀️ виходить у продакшн для всіх (гейміфікація) —
  прибирається умова `DEV_MODE` навколо `ThemeToggle` + мікроанімація
  перемикання (обертання іконки 180°, `--dur-pop` 180ms).
- Команда обирає A чи B до впровадження (можна A+B разом).

## 4. Позначки: стікер на візуалі

- Новий **стиль відображення** капсули: наліпка поверх 3D-сцени — жовта/кислотна
  плашка `rotate(-3deg)`, легка тінь, верхній правий кут стейджа,
  `pointer-events: none` (не перехоплює драг).
- Дані: нове поле `label_style VARCHAR(20) DEFAULT 'capsule'`
  (значення: `capsule | sticker`) на **collections і products**. Міграція —
  двома `ALTER TABLE`. Рендер: `sticker` → плашка на сцені; `capsule` → чинна
  пігулка біля назви. Кольори — ті самі `label_color` (для стікера рекомендовано
  `#CCFF00` або `#f5d800`, текст завжди чорний — авто-правило розширюється:
  на acid-фонах текст темний).
- Крапка (`badge_*`) — без змін.

## 6. Ризики / перевірки

- Автогортання = двигун ажіотажу і водночас подразник: обов'язкові пауза на
  взаємодію і reduced-motion-вимкнення (обидва в спеці).
- Acid на світлій темі: якщо режим «завжди темна» НЕ приймуть — кожне
  вживання `--acid` перевіряти правилом «тільки фон+чорний текст».
- `#FF0000` — стежити за дрібними цінами (правило двох червоних у таблиці).
- Стікер перекриває сцену: верхній правий кут і `pointer-events:none`
  (перевірений патерн крапки-над-сценою).
