> мінімум руху, покупець сам керує швидкістю. Найменша дельта до чинної
> системи з трьох концепцій.

## 2. Герой: Таби колекцій (кандидат 1)

- Над героєм — pill-таби всіх колекцій (назви з БД; активна — чорна пігулка,
  решта — прозорі з межею `--border-subtle`). При >3 колекціях ряд скролиться
  горизонтально (scrollbar схований).
- **Одна 3D-сцена на всю головну** (WebGL = 1, найощадніший з кандидатів).
  Перемикання таба міняє `designs` сцени; якщо активний товар обох колекцій на
  спільній базовій футболці — канвас НЕ ремонтується (лише своп текстури),
  власна модель — штатний remount по `modelUrl`.
- Під сценою: заголовок, опис, капсула/крапка колекції з БД, «До колекції»
  (веде на вибраний дизайн активної колекції), для першої колекції — «Про бренд».
- Жодного автогортання. Стан вибраних дизайнів — словник на колекцію (чинний).
- Порядок табів = `sort_order`; архівна колекція отримує в табі суфікс-мітку
  «архів» (сірий, `--text-tertiary`).

## 3. Теми

- **Без змін**: автоматика 18:00–6:00 лишається як «жива» фішка бренду
  (магазин реагує на реальний час). Тумблер — лише `DEV_MODE`.
- Єдина добавка: у футері дрібний рядок «🌙 нічна тема вмикається о 18:00» —
  щоб поведінка читалась як задум, а не збій (копі узгодити з власником).

## 4. Позначки: тільки градієнт-капсула

- Всі лейбли (`label_*`) — на фірмовому градієнті: значення поля
  `label_color = 'var(--gradient-brand)'` для КОЖНОЇ активної позначки
  (міграція даних одним UPDATE; механіка вже це вміє, текст на градієнті
  автоматично темний).
- Гайд: жодних сторонніх кольорів у капсулах — лише чорне/біле/градієнт.
  Кольорові статуси лишаються крапці (`badge_*`): зелена «класика»,
  червона `#B8503B` «останні розміри».
- Стікери не використовуються.

## 6. Ризики / перевірки

- Одна сцена = один LCP-канвас: постер активної колекції має пріоритетне
  завантаження (`priority` на рендері першої колекції).
- Смарагдовий лінк поряд із зеленим статусом наявності (`#16a34a`) — два зелені
  сенси поруч; розвести кеглем/вагою або зсунути статус-зелений у той самий
  смарагд (рішення дизайнера при впровадженні).
- Таб-перемикання без remount перевірити на парі «текстурна колекція ↔
  колекція з моделями» (Оксана ↔ Вар'ятство).
