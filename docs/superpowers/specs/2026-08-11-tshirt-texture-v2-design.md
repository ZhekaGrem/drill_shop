# Новий принт футболки (texture v2) + вимкнення стрибка

**Дата:** 2026-08-11
**Гілка:** `v2`
**Статус:** спека затверджена в чаті, виконання інлайн

---

## Задача

Користувач додав нову basecolor-текстуру `tshirt 3d/new texture 1.png`
(7936×7936, чорне тло, принти на тих самих UV-островах, що й чинна розкладка).
Треба: запекти її в модель героя, оновити фолбек-фото, вимкнути стрибок.

## Пайплайн

1. **Стиск текстури:** 7936² PNG → 2048² JPEG q88 через sharp (з node_modules).
2. **Бейк у GLB:** байтова заміна image `basecolor2_2048` всередині
   `public/model/tshirt.glb` (перебудова BIN-чанка зі зсувом bufferView'ів;
   стиснена геометрія і normal map лишаються байт-у-байт). Ім'я image →
   `basecolor3_2048`. Старий GLB → бекап `tshirt 3d/tshirt-prev.glb`.
3. **Перевірка суміщення:** headless Blender-рендер 4 ракурсів ДО підстановки;
   контролер звіряє посадку принтів оком.
4. **Фолбек:** фронт-рендер із прозорою плівкою → 1200×1200 webp →
   `public/assets/img/tshirt-fallback.webp`.
5. **Стрибок:** проп `interactive?: boolean` на `TshirtScene`, **дефолт false**
   (обробники, курсор і `jump.step` не підключаються; хук викликається завжди —
   правило хуків). `HeroVisual` не змінюється → стрибок вимкнено на сайті.
   Повернути: `<TshirtScene interactive ...>`. Вітер і обертання не чіпаються.

## Відомі прийняті нюанси

- Третя UV-панель (внутрішній шар тканини) у новій текстурі порожня —
  внутрішня поверхня стане однотонно чорною. Оцінюємо на рендері; якщо
  непомітно в сцені — приймаємо.
- Фолбек рендериться моїм пайплайном (автокадрування), не оригінальним
  T28-сетапом — композиція буде близькою, не піксель-у-піксель (наявний
  deferred minor про ~25px розбіжність фото/3D і так стоїть у беклозі).

## Перевірка

- Рендери: принти сидять на грудях/спині без швів і зсувів.
- `npx tsc --noEmit`, ESLint по зміненому файлу, `npm run build` зелені.
- Браузер: клік по футболці нічого не робить, курсор звичайний; вітер і
  обертання живі; фолбек показує новий принт.

## Коміти (pathspec!)
