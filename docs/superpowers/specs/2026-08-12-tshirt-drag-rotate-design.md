# Drag-обертання футболки поверх живого idle-руху

**Дата:** 2026-08-12
**Гілка:** `v2`
**Статус:** спека затверджена користувачем наперед («зразу пиши і реалізуй»)

---

## Задача

Дати користувачу крутити футболку вліво/вправо пальцем чи мишею, НЕ зупиняючи
життя сцени: під час драгу тканина далі дихає вітром і реагує відставанням на
рух руки, а після відпускання футболка **плавно продовжує власний idle-рух**
(дихаючий оберт, нахили, дрейф) з того кута і з тієї швидкості, де її залишили.

## Взаємодія

| Аспект            | Поведінка                                                                  |
| ----------------- | -------------------------------------------------------------------------- |
| Захоплення        | pointerdown на всій зоні візуала (`.stage`), не лише на пікселях футболки  |
| Чутливість        | 0.01 рад/px (~0.57°/px): свайп на 300px ≈ пів оберту                       |
| Напрям            | тягнеш вправо — лицьова поверхня їде вправо («схопив за тканину»)          |
| Під час драгу     | кут веде рука; дихання ω на паузі; нахили/дрейф/вітер живуть; **lag тканини реагує на швидкість руки** (різко смикнув — поділ гойднувся) |
| Відпускання       | кутова швидкість руки підхоплюється як momentum і за ~0.4 с експоненційно згасає в поточну idle-ω — без стрибка ні кута, ні швидкості |
| Кламп швидкості   | |ω драгу| ≤ 8 рад/с (захист від флік-абсурду)                              |
| Мобайл            | `touch-action: pan-y` на stage: вертикальний скрол сторінки живий, горизонтальний драг — наш; pointer capture тримає драг за межами зони |
| Курсор            | `grab` над зоною, `grabbing` під час драгу                                 |

## Архітектура

- **`useDragRotation.ts`** (новий, DOM-рівень): хук у HeroVisual. Стан у ref
  (`DragState = { active, pendingAngle, velocity }`), повертає обробники
  pointer-подій для `.stage` і сам ref. Тільки primary-pointer (мультитач:
  другий палець ігнорується), velocity згладжується між подіями.
- **`useIdleMotion`** приймає опційний `dragRef` і споживає його в step:
  - drag active → `angle += pendingAngle` (обнулити), ефективна ω = кламп
    швидкості руки; інтеграл дихання не тікає;
  - реліз (перехід active→false) → `momentum = ω_руки − ω_idle`, далі
    `momentum *= e^(−2.2·dt)`; кут інтегрується як `(ω_idle + momentum)·dt`;
  - **єдиний ω-конвеєр**: ефективна ω (рука/momentum/idle) живить наявний
    α→lag ланцюг — тканина фізично реагує на всі переходи безкоштовно.
- **`TshirtScene`**: прозорий проп `dragRef` → у `Tshirt` →
  `useIdleMotion(dragRef)`. Жодної нової логіки в сцені.
- **`HeroVisual`** (WIP, не комітити): виклик хука, обробники на `.stage`,
  CSS `touch-action: pan-y` + курсори.

Стрибок (`interactive`) вимкнений і не конфліктує: drag живе на DOM-рівні,
а не на R3F-рейкасті групи. Жодних змін шейдера → без пасток HMR.

## Крайові випадки

| Випадок                            | Поведінка                                                   |
| ---------------------------------- | ----------------------------------------------------------- |
| Палець виїхав за межі stage        | pointer capture — драг триває до відпускання                |
| Другий палець (pinch)              | ігнорується (primary-only)                                  |
| pointercancel (скрол переміг)      | як реліз: momentum підхоплюється з останньої швидкості      |
| Reduced motion (сцени немає)       | обробники висять на фото без ефекту — no-op                 |
| Драг під час completed-зуму Bounds | кут у idle-інтегралі — Bounds не рефітиться від rotation     |
| Фонова вкладка під час драгу       | кламп dt в idle-step як і раніше                            |

## Тестування

Ручна перевірка + жива вкладка-проба (real drag через розширення):
- потягнув — крутиться за рукою; відпустив — плавно перейшла у власний рух;
- різкий флік — момент видно і згасає; тканина гойдається на переходах;
- вертикальний скрол сторінки з тачпаду/пальця над футболкою не зламаний;
- свотчі дизайнів клікаються (вони поза stage);
- `npx tsc --noEmit`, ESLint по змінених файлах, `npm run build` зелені.

## Свідомо не робимо (YAGNI)

Вертикальний drag (pitch), обертання за інерцією у зворотний бік, drag-скрол
фолбек-фото при reduced-motion, кінетична фізика з тертям за палець.
