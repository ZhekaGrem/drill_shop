# «Злипні»

Два життя одного розділу:

- **Розділ «є. Злипні»** (`/zlypni`, продаж з 2026-11-21): «Футболляндручки» (5 футболок, 1300 грн) і «Боби» (3 худі, 2300 грн) з фінальних комплектів дизайнерів, S–XXL по 100 на розмір. Своя словомарка в хедері (`nav-worlds.ts`); у каталозі й на головній його товарів нема (`hidden-collections.ts`), як у «є. \*\*\*». Лонгсліви з тих самих комплектів чекають рішення власника (нижче).
- **Прихована галерея** (`/zlypni/<ключ>`): двісті дизайнів 2026-11-16 («Футболярчики» і «Бобаночки»), зняті з продажу 2026-11-17 рішенням власника. Товари й колекції прибрані з БД міграцією бекенда `20261117000000_retire_zlypni` (м'яке видалення, як у Поламава), а дизайни показує галерея без цін, розмірів і кошика — лише за посиланням, яке власник надсилає вибраним клієнтам.

## Розділ: комплекти → сайт

Комплекти лежать у `../злипні дизайн /` (пробіл у кінці назви): `футболка/дизайн 7–11`, `худі/дизайн 1–3`, `лонгслів/дизайн 4–6`. У кожному — принти для друку (`груди`, `спина`, `рукав`, `бірка`: SVG і PNG 600 ppi), `3D/` (GLB із геометрією сайтової моделі й запеченим дизайном, повна UV-розгортка в розмірі шаблону, `текстура-4096.webp` для сайту, рендери перед/спина) і `відео/` (`оберт.webp` 480×600 × 48 кадрів і `постер.webp` — формат карток каталогу, `відео.mp4` 960×1200 для соцмереж). Назви товарів — із `ПРОЧИТАЙ.txt` комплектів.

Єдине джерело розділу — `src/shared/config/zlypni-merch.json`: розміри, залишок на розмір, колекції з ціною й описом, товари з назвою, текою комплекту (`kit`) і текстурою (`mapUrl`, пише скрипт). Описи колекцій — чернетки, власник править до фази `create`.

```sh
# 1. Перевірити комплекти (геометрія сайтових моделей, розміри файлів) і перенести:
#    текстури → public/3d/textures/zlypni/<stem>.webp (+ ?v= у маніфесті),
#    фото карток → 3d/artists/zlypni/merch/catalog-images, оберти → 3d/artists/zlypni/merch/turntables
node scripts/zlypni/import-kits.cjs
# 2. push v2 — текстури мають віддаватись фронтом до activate
# 3. База (лише читання без --apply; запис потребує --apply --confirm=zlypni)
node scripts/zlypni/create-collection.cjs --phase=check
node scripts/zlypni/create-collection.cjs --phase=create --apply --confirm=zlypni
node scripts/zlypni/create-collection.cjs --phase=images --dir=3d/artists/zlypni/merch/catalog-images --apply --confirm=zlypni
# 4. Оберти для карток (копія скрипта мусить лежати в бекенді, щоб знайти його пакети)
cp 3d/pipeline/upload-turntables.mjs ../drill-shop-backend/scripts/.tmp-upload-turntables.mjs
(cd ../drill-shop-backend && node scripts/.tmp-upload-turntables.mjs ../drill_shop/3d/artists/zlypni/merch/turntables && rm scripts/.tmp-upload-turntables.mjs)
# 5. Увімкнути (гейт: асети на проді, фото й рендери в БД, модель і розміри ті самі)
node scripts/zlypni/create-collection.cjs --phase=activate --probe=https://ye-dril.com --apply --confirm=zlypni
# Інший залишок: --phase=stock --qty=N; сховати назад без деплою: --phase=deactivate
```

`create` вставляє колекції й товари неактивними, тож між деплоєм фронта й `activate` сторінка `/zlypni` показує «Розділ скоро відкриється». Старий магазин shchilnuidrill.com (той самий бекенд, без списку прихованих колекцій) показує ці товари у своєму каталозі.

**Лонгсліви** («Longslivchansky», 2000 грн за брифом): комплекти 4–6 готові, але окремої 3D-моделі лонгсліва нема — у комплектах він показаний на моделі худі. Варіанти: продавати на моделі худі з підписом, купити/знайти модель лонгсліва (нові шаблони розгорток, розкладка принтів і рендери — 1–2 дні), або без 3D. Коли власник вирішить — третя колекція в `zlypni-merch.json` і той самий конвеєр.

## Галерея

`src/app/zlypni/[key]` → `widgets/ZlypniGallery`. Дані — з репозиторію, БД галерея не читає:
`src/shared/config/zlypni-gallery.json` (назви, текстури, постери), текстури в `public/3d/textures/zlypni/<колекція>/`,
постери 640² у `public/zlypni`. Клік по постеру ставить дизайн на сцену й прокручує до неї; сітка
показує 12 постерів і далі «Показати ще» по 24. Мапи довгої колекції сцена не префетчить
(`HeroVisual`, `PREFETCH_ALL_UP_TO`), а компас вантажить мініатюри лише поруч з активною
(`CompassSwitcher`, `EAGER_RADIUS`).

**Ключ.** Репозиторій публічний, тож у коді лише `ZLYPNI_PREVIEW_KEY_SHA256` (`src/shared/config/zlypni.ts`),
а сам ключ — у власника. Будь-який інший ключ дає «не знайдено» з `noindex`. Змінити посилання (наприклад,
якщо воно розійшлося ширше, ніж треба): згенерувати новий рядок, покласти в конфіг його SHA-256 і задеплоїти —
старе посилання перестане працювати.

```sh
node -e "const k=require('crypto').randomBytes(21).toString('base64url');console.log(k, require('crypto').createHash('sha256').update(k).digest('hex'))"
```

`ZLYPNI_RETIRED_SLUGS` лишаються в `hidden-collections.ts` (як і Поламав): навіть застарілі дані не мають
показати ці товари в магазині.

### Розгортки

Дизайнери малюють на шаблонах з `../Злипні/шаблони розгорток` (`scripts/zlypni/make-templates.py`): контури деталей, маска, підписи й аркуш «що де на 3D». Деталі визначено за геометрією моделей і перевірено рендером: кожну пофарбовано своїм кольором, модель знято з чотирьох боків. Виворіт спини футболки, підкладку корпусу й рукавів худі не видно; пояс худі в шаблоні перевернутий.

Перший комплект — `../Злипні/uv-2026-11-16`: 100 футболок і 100 худі, PNG 4096² на тих самих моделях (SHA-256 збігаються з `public/3d/models`), назви й номери в `manifest.json`. Однакові назви сімейства отримують номер варіанта: «Липкий знак №1…№5».

### Конвеєр галереї

```sh
# 1. Розгортки → public/3d/textures/zlypni/<колекція>/NNN.webp (4096² q90) і scripts/zlypni/catalog.json
/opt/homebrew/bin/python3.14 scripts/zlypni/import-uv.py "../Злипні/uv-2026-11-16"
# 2. Кожен дизайн на моделі спереду й ззаду (пропускає вже свіжі кадри)
/Applications/Blender.app/Contents/MacOS/Blender --disable-autoexec -b -P scripts/zlypni/render-posters.py -- "$PWD"
# 3. Кадри → render3d (і фото для карток), контактні аркуші для перевірки
node scripts/zlypni/publish-images.cjs
/opt/homebrew/bin/python3.14 scripts/zlypni/contact-sheet.py   # 3d/artists/zlypni/*-превʼю.jpg
# 4. Постери галереї й zlypni-gallery.json
node scripts/zlypni/export-gallery.cjs
```

`import-uv.py` зупиняється на неквадратних, замалих і прозорих файлах і попереджає, коли багато малюнка поза деталями (чужа викрійка або свідома заливка всього аркуша — остаточно вирішують рендери).

Двісті дизайнів галереї в БД не повертаються: `create-collection.cjs` тепер засіває лише розділ із `zlypni-merch.json`, а `catalog.json` живить тільки галерею.
