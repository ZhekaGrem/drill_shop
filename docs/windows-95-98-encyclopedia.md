# Енциклопедія інтерфейсу Windows 95/98 для єДріл

Цей документ пояснює візуальну мову Windows 95/98 і визначає її застосування в магазині єДріл. Історична довідка відокремлена від наших рішень для сучасного вебсайту. Це робоча специфікація оформлення, а не копія операційної системи.

## 1. Походження

Windows 95 вийшла 24 серпня 1995 року. Меню «Пуск» і панель завдань стали центральними елементами нового інтерфейсу. Ці відомості підтверджує [ретроспектива Microsoft](https://blogs.windows.com/windows-insider/2020/08/24/looking-back-the-25th-anniversary-of-windows-95/).

Windows 98 вийшла 25 червня 1998 року. Дата зафіксована в [історії Microsoft за 1998 рік](https://learn.microsoft.com/en-us/shows/history/history-of-microsoft-1998). Дві версії належать до однієї впізнаваної родини оформлення; для єДріл вони утворюють спільну концепцію `win98`.

Це історичне джерело структури, а не вимога відтворити кожну його деталь у вебмагазині.

## 3. Геометрія: світло створює кнопку

Власне правило нашої реалізації: верхній і лівий краї піднятої поверхні світлі, нижній і правий — темні. Для втиснутої поверхні напрямок міняється. Тому натискання видно без масштабування, пружини або довгої анімації.

Піднята поверхня:

```css
box-shadow:
  inset 1px 1px var(--win-highlight),
  inset -1px -1px var(--win-frame),
  inset 2px 2px var(--win-light),
  inset -2px -2px var(--win-shadow);
```

Втиснута поверхня:

```css
box-shadow:
  inset 1px 1px var(--win-shadow),
  inset -1px -1px var(--win-highlight),
  inset 2px 2px var(--win-frame),
  inset -2px -2px var(--win-light);
```

Кути прямі. Розмитої тіні навколо кожної кнопки немає. Додаткова жорстка тінь дозволена під вікном, щоб відокремити його від робочого столу.

## 4. Палітра

Наведені значення — канонічні токени адаптації єДріл. Історичні системи дозволяли налаштовувати кольори, тому їх не слід трактувати як єдину палітру всіх комп’ютерів Windows 95/98.

| Токен             | Колір     | Роль                          |
| ----------------- | --------- | ----------------------------- |
| `--win-desktop`   | `#008080` | Робочий стіл                  |
| `--win-face`      | `#c0c0c0` | Вікна, кнопки, панель завдань |
| `--win-paper`     | `#ffffff` | Поля й області вводу          |
| `--win-title`     | `#000080` | Початок смуги заголовка       |
| `--win-title-end` | `#1084d0` | Кінець градієнта заголовка    |
| `--win-highlight` | `#ffffff` | Світлий край                  |
| `--win-light`     | `#dfdfdf` | Друга світла лінія            |
| `--win-shadow`    | `#808080` | Темний край                   |
| `--win-frame`     | `#000000` | Зовнішня межа                 |

Текст на сірому тлі — чорний або темно-сірий. Назва в синій смузі — біла. Червоний лишається кольором помилки або промо, зелений — підтвердження. Контент і статуси мають залишатися читабельними без розпізнавання кольору.

## 5. Windows 95 та Windows 98 як референси

Для цієї концепції від Windows 95 беремо ясну геометрію, робочий стіл і виразний натиснутий стан. Від Windows 98 — м’якший перехід синьої смуги заголовка. Це дизайнерський синтез, який не претендує на повне відтворення конкретної збірки ОС.

Для впізнаваності важливіші чотири речі: бірюзове тло, сірий рельєф, синя смуга й панель завдань. Сам піксельний шрифт або декоративний старий курсор не замінюють цієї системи.

## 6. Типографіка

У реалізації використовується системний стек `Tahoma, Verdana, Arial, sans-serif`. Це практичний вибір для читабельної української мови на сучасних пристроях; він не видається за точну копію історичного растрового системного шрифту Windows 95.

- Основний текст: близько 16 px, звичайне накреслення.
- Допоміжні написи: 13–14 px.
- Заголовки вікон: 14 px, жирні.
- Назви колекцій: 28–40 px залежно від ширини.
- Ціна: виразна вага, табличні цифри там, де це вже підтримує компонент.

Текст залишається живим, доступним для виділення, пошуку, перекладу й масштабування. Растрові написи та примусове вимкнення згладжування не використовуються.

## 7. Анатомія вікна колекції

```text
┌────────────────────────────────────────────────┐
│ 📁 Назва колекції                  [копіювати] │
├────────────────────────────────────────────────┤
│ Назва колекції          3D-виріб               │
│ Опис                   Вибір дизайну          │
│ [До колекції]   Про бренд                      │
└────────────────────────────────────────────────┘
```

На вузькому екрані порядок: смуга заголовка → 3D-виріб і перемикач → назва, опис і дії. Вікна йдуть звичайним потоком сторінки. Їх не потрібно перетягувати, розкладати по координатах або відкривати подвійним натисканням.

Назва у смузі допомагає впізнати вікно. Іконка копіювання стоїть у правому верхньому куті заголовка; після копіювання вона плавно змінюється на галочку. Кнопка «До колекції» стоїть у блоці дій нижче, окремо від копіювання. Нижня велика назва зберігає ієрархію сторінки: перша колекція має `h1`, наступні — `h2`.

Кнопка зі стрілкою відкриває сторінку вибраного товару. Декоративних «закрити», «згорнути» й «розгорнути», які нічого не роблять, немає. Це узгоджується з [рекомендаціями Microsoft щодо заголовків вікон](<https://learn.microsoft.com/en-us/previous-versions/windows/desktop/bb226827(v=vs.85)>): команди в смузі заголовка повинні мати визначену дію.

### Вікно товару в каталозі

Картка товару в `/catalog`, на сторінках категорій і в добірках — окреме вікно, за тим самим підходом, що вікна блоків
сайту «Радіо Цибуля» (його `docs/windows-95-98-encyclopedia.md` §7): кожен блок — вікно зі смугою, справжній заголовок
блоку сам стає смугою, зображення — на втиснутому кольоровому «екрані», головна дія — кнопка за замовчуванням.

```text
┌─────────────────────────────────┐
│▓▓ 🎁 Боба Зелена Оксана ▓▓▓▓▓▓▓▓│  ← смуга = посилання з назвою (h3), відкриває товар
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │   бірюзовий втиснутий       │ │  ← «екран»: мініатюрний робочий стіл
│ │   екран з 3D-оберткою/фото  │ │
│ └─────────────────────────────┘ │
│ ─────────────────────────────── │  ← витравлена лінія
│ 2200₴           [M][L][XL][XXL] │  ← розміри: кнопки-перемикачі
│ ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓ │
│ ┃   🛒 Додати в кошик         ┃ │  ← кнопка за замовчуванням (чорна рамка)
│ ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛ │
└─────────────────────────────────┘
```

| Частина               | Було                                                      | Стало                                                                                                                                                          |
| --------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Рамка                 | Піднята сіра плитка з чорною межею 1 px, як велика кнопка | Рамка вікна `--win-window`: зовнішня лінія сіріша, ніж у кнопки — вікно не плутається з кнопкою                                                                |
| Назва                 | Жирний текст під фото                                     | Синя смуга заголовка з іконкою: це той самий `h3` у тому самому посиланні, перенесений нагору (`display: contents` на обгортках, `order: -1`), без копії назви |
| Фото                  | На сірому тлі картки, без межі                            | На втиснутому «екрані» кольору робочого столу `#008080`: на ньому видно і білі, і чорні речі (на білому зникали білі футболки)                                 |
| Розміри               | Сірі чіпи з рамкою                                        | Підняті кнопки; вибраний — втиснутий на шаховому тлі й жирний, як натиснута кнопка панелі інструментів; недоступний — сірий тиснений текст                     |
| Кнопка                | Піднята сіра                                              | Кнопка за замовчуванням: чорна рамка навколо рельєфу; натиснута — втиснута                                                                                     |
| «Немає в наявності»   | Сірий текст із крапкою                                    | Тонко втиснуте поле рядка стану з темно-червоним текстом                                                                                                       |
| Бейджі («ХІТ», акції) | Пігулки                                                   | Наліпка доби: жовта, червоний текст, чорна рамка                                                                                                               |
| Сітка                 | Картки просто на сірій сторінці                           | Темно-сіра втиснута робоча область (колір «AppWorkspace» програм, що тримають кілька документів), у ній вікна товарів                                          |
| Сторінка              | Сіра панель без назви                                     | Вікно «Каталог — Є.Дріл» (смуга з CSS, альтернативний текст порожній — читається справжній `h1`); лічильник «46 товарів» — поле рядка стану                    |
| Завантаження          | Скелетони-картки                                          | Ті самі вікна з неактивною сірою смугою                                                                                                                        |

Вікно не реагує на курсор рухом: без підйому й без збільшення фото. Наведення на смугу підкреслює назву, як посилання
в Internet Explorer 4; фокус клавіатури — білий пунктир усередині смуги. На телефоні розміри й кнопка — 44 px. Кнопок
«закрити» / «згорнути» в смузі немає: дія смуги одна — відкрити товар.

Реалізація: `ProductCard.module.scss` (блок `:global([data-design='win98'])`), `Badge.module.scss`,
`app/catalog/catalog.module.scss`, `category.module.scss`, міксин `shared/styles/_win98.scss` (`page-window`), токени в
`app/windows98.css`. Розмітку картки не змінено.

## 8. Кнопки та зворотний зв’язок

Кнопка має сіре тло, рельєф і чіткий підпис дії. При натисканні рельєф стає втиснутим. При фокусі клавіатурою з’являється пунктирний контур. Недоступні дії мають справжній `disabled`, а не лише інший колір.

[Рекомендації Microsoft щодо командних кнопок](<https://learn.microsoft.com/en-us/previous-versions/windows/desktop/bb246415(v=vs.85)>) пов’язують натискання з виконанням конкретної дії. У єДріл зберігаються зрозумілі назви «До колекції», «Додати в кошик», «Оформити замовлення». Купівля не перейменовується на запуск програми.

Кнопка копіювання посилання зберігає попередню домовленість: після успіху іконка переходить у галочку; окремий напис «Посилання скопійовано» не з’являється.

## 9. Панель завдань

Панель закріплена знизу лише у `win98`:

| Посилання | Адреса     | Призначення                     |
| --------- | ---------- | ------------------------------- |
| Пуск      | `/menu`    | Справжня сторінка меню магазину |
| єДріл     | `/`        | Повернення на головну           |
| Каталог   | `/catalog` | Пошук і перегляд товарів        |
| Кошик     | `/cart`    | Керування замовленням           |

Поточний розділ позначений `aria-current` і втиснутим станом. Напис «єДріл / 98» у правій області — позначення оформлення, а не фальшивий годинник або індикатор з’єднання. На телефоні він прибирається заради навігації.

Під основним контентом зарезервовано місце під панель і системну безпечну зону. Панель не повинна перекривати останні кнопки сторінки.

## 10. Форми, кошик і оформлення

Поля отримують світлу втиснуту поверхню. Селект, поле телефону, промокод, доставка та оплата зберігають свої існуючі правила. Заголовки модальних вікон і шухляд кошика мають синю смугу з білим текстом.

Замовлення залишається звичайним процесом магазину: товар → параметри → кошик → доставка → оплата. Інтерфейс не додає зайвих вікон підтвердження заради стилю.

Усі грошові значення, залишки, промокоди та доступність надходять із наявної системи. Тема змінює оформлення компонентів, а не каталожні дані.

## 11. 3D та завантаження

Зберігається механіка, погоджена перед цією темою:

1. Під час початкового рендера конкретної моделі показується спінер.
2. Статична фотографія перед 3D не з’являється.
3. Показ починається після готовності текстури й завершеного кадру.
4. При зміні принта на вже відрендереній моделі сцена залишається видимою.
5. Старий принт залишається до застосування нового; повторного спінера для такого свопу немає.
6. При завантаженні іншої моделі її новий Canvas чекає власного першого кадру.

Для `win98` обрана анімація `showcase`, щоб передній і задній принти можна було роздивитися. Рух моделі залишається частиною товарної презентації. Додаткових WebGL-фонів, ефектів CRT або відеошпалер тема не створює.

## 12. Іконки й графіка

Колекцію позначає невелика жовта папка. Панель завдань використовує зрозумілі іконки меню, головної, каталогу й кошика. Це наявні в проєкті SVG-іконки Tabler з колірною адаптацією.

Власний бренд єДріл залишається на місці. Логотип Windows, системні звуки, скриншоти ОС і сторонні набори історичних іконок до продукту не додавалися. Об’єм інтерфейсної графіки малий; важкими активами залишаються самі 3D-товари.

## 13. Мобільна адаптація й доступність

Історичний масштаб настільної ОС не переноситься на телефон буквально. Власні правила адаптації:

- Основні дії та посилання панелі мають висоту щонайменше 44 px.
- Елементи не вимагають hover або подвійного кліку.
- Назви колекцій переносяться, заголовок вузького вікна може скорочуватися з багатокрапкою.
- Фокус клавіатури залишається видимим; посилання мають назви.
- Модальні вікна використовують наявне керування фокусом Mantine.
- Немає заборони масштабувати сторінку чи збільшувати текст.
- Зберігається підтримка `prefers-reduced-motion` та системного режиму примусових кольорів.

Світле оформлення використовується автоматично. Якщо відвідувач явно закріпив темну тему, використовується сучасна темна адаптація зі сталевими панелями. Вона не є історичною палітрою Windows 98.

## 14. Активація та сумісність

Ідентифікатор концепції — `win98`. У режимі «Авто» вона є поточним дизайном магазину, календарна ротація призупинена. Це централізовано налаштовано через `DEFAULT_AUTO_DESIGN` і `ROTATION_ENABLED`.

Інлайн-скрипт ставить атрибут теми перед першим кадром. Клієнтська логіка використовує ту саму конфігурацію. Явний вибір попередньої концепції у конкретному браузері має вищий пріоритет. Через `/v2/dev` можна вибрати Windows 95/98 або повернути інший дизайн.

Попередні концепції збережені. CSS Windows 95/98 обмежений `[data-design='win98']`; додані смуга вікна та панель завдань приховані в інших дизайнах. Сторінки без оболонки магазину, зокрема гра `/moto`, не отримують панель завдань.

## 16. Як продовжувати цей дизайн

Новий компонент спочатку має отримати звичайну семантику й робочу дію, потім — оформлення Windows. Для поверхні використовуй `--win-face`, для читання/вводу — `--win-paper`, для рамки — `--win-raised` або `--win-sunken`. Не копіюй багатошарові тіні вручну в кожен компонент.

Новий стан має бути видимим через текст, форму або рельєф. Помилки повідомляють, що не вдалося і що зробити далі. Декоративна ностальгія не повинна змушувати людину шукати кнопку купівлі або вчитися керувати настільною ОС.

Перед публікацією перевіряй вузький екран, клавіатуру, збільшений текст, довгі назви товарів, кошик і поля замовлення. Окремо перевіряй перемикання на іншу концепцію: жодна частина Windows-оформлення не має залишатися в ній.
