# Сід-пакет: колекції + 3D-поля товарів

Готові дані для наповнення БД після міграції зі спеки
`docs/superpowers/specs/2026-08-13-collections-db-design.md`.

## Що всередині

- `mapping.json` — колекція «Ніжна Оксана»: 8 живих товарів каталогу з
  порядком у перемикачі, шляхом крою, текстурою, рендером-мініатюрою і
  порахованим свотчем (палітра з рендера: тканина + акцент принта).
- `seed.template.cjs` — скрипт для БЕКЕНД-репо: заливає текстури/рендери в
  Cloudinary і проставляє поля. Ідемпотентний. Файли бере з чекаута
  drill_shop (`FRONTEND_DIR`), самі файли вже закомічені в
  `public/3d/textures/` і `public/assets/img/`.

## Порядок

1. У бекенд-репо накотити міграцію зі спеки (Collection + колонки Product +
   ProductImage.kind).
2. Скопіювати `seed.template.cjs` у бекенд-репо, за потреби підігнати під
   локальні хелпери Cloudinary.
3. `FRONTEND_DIR=/шлях/до/drill_shop node seed.template.cjs`

## Розширення

- **«Щільний Дріл» (16 дизайнів dril1/dril2):** текстури й рендери вже в
  репо (`tshirt-dril{1,2}-0{1..8}`), але пари дизайн→товар не звірені з
  власником. Коли будуть — додати другий блок у `mapping.json` за зразком.
- **Вініл/касета:** після появи геометрій у реєстрі моделей — записи з
  `model3dPath: '/3d/models/vinyl.glb'` тощо.
- Свотчі для нових товарів: `palette`-алгоритм (порт на бекенд зі
  скретчпад-скрипта сесії; вхід — render3d, вихід — hex/conic-gradient).
