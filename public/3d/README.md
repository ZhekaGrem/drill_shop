# public/3d — що деплоїться

Тут лежить ЛИШЕ те, на що хтось посилається: база (`model3dPath`,
`texture3dUrl`) або код. Усе інше живе поза репозиторієм, у `3d/unused/`.

```
models/                 спільні крої, пласким списком: моделі не належать
                        жодному світу, а tshirt.glb прописаний у двох десятках
                        товарів і в коді — тека під нього тільки додала б змін
  tshirt.glb            дефолтний крій (TshirtScene, useCollections)
  hoodie-buba.glb       «Культурний Фронт», текстура запечена
  hoodie-polamav.glb    худі Поламава: UV-трансформація запечена, свопи працюють
  hoodie.glb            мокап BrockCreative — лише дев-сторінка /v2/lab
  sticker-pack-a5.glb   аркуш стікерів; колекція зараз прихована (heroEnabled=false)

textures/<світ>/        текстура належить світу, а не крою
  dril/                 «Гонорове варʼятство»: tshirt-apex, tshirt-kalach
  olko/                 «є. Олько»
  serik/                «є. Сєрік»
  polamav/              «є. Поламав»: tshirt-01..07, hoodie-01..06
  lab/                  тільки для /v2/dev і /v2/lab, у продажу не бере участі
```

Правила:

- **Шлях текстури зберігається в базі.** Перейменування або перенесення — це
  міграція: спершу деплой, де файл є на обох місцях, тоді
  `node scripts/3d/retarget-textures.cjs --apply --confirm=3d`, і аж тоді
  деплой, що прибирає стару копію.
- **`public/3d/models/` у `.gitignore`.** Нова модель додається через
  `git add -f`, інакше деплой мовчки поїде без неї.
- **Мертві асети не видаляємо, а переносимо** у `3d/unused/` (тека поза git):
  файли лишаються на диску власника, а з деплою зникають.
- Частина колекцій тримає текстури в Cloudinary (`products/3d-textures/…`) —
  їх тут немає і вони цих правил не стосуються.
